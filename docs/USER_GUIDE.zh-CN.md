# SOPscape Council 用户操作指南

## 快速演示

进入工作区后点击顶部的 **演示 / 指南**，再点击 **一键启动钓鱼邮件演示**。该模式使用仓库内经过 Schema 校验的 Fixture，不调用真实模型、不产生模型费用，也不会写入历史记录。

## 完整流程

1. **登录**：使用工作区账号登录。Owner、Editor 可以执行写操作，Viewer 只能查看。
2. **输入 SOP**：在“议会指挥室”粘贴标题和正文，或导入 TXT、Markdown、JSON、CSV、EML、PDF、DOCX。
3. **启动审查**：点击“启动议会演练”。系统并行运行流程分析员、风险挑战者、证据审计员，再由 Moderator 聚合。
4. **阅读结果**：查看共识、分歧、证据缺口、建议路径、决策节点和数字护照。
5. **浏览 3D 场景**：共识、风险、证据标签切换不同视图；桌面端按住鼠标中键拖动旋转 360°，点击“复位视角”恢复默认相机。
6. **完成训练**：逐个选择决策节点。所有节点完成后，系统保存评分、后果和教练建议。

## 工作区功能

| 功能 | 操作 |
|---|---|
| 历史记录 | 打开“History”，重新打开已保存的演练。 |
| 证据档案 | 打开“Evidence”，查看证据缺口和审计信息。 |
| 版本比较 | 在 SOP 工作台保存新版本后比较风险和准备度变化。 |
| 团队管理 | 在“Security”中邀请成员、调整 Owner/Editor/Viewer 权限。 |
| 分享报告 | 在结果面板创建只读链接；不要把工作区凭证放入链接或 URL。 |
| 协议接口 | 在“Protocol”查看 A2MCP/MCP 请求结构；受保护接口需要 Bearer API Key。 |
| 主题/语言 | 顶部选择跟随系统、浅色或深色，以及 10 种界面语言。 |

## 失败与重试

- 502：上游模型无效、空响应或恢复耗尽；不会返回不完整的正式结果。
- 504：整场演练超过 58 秒截止时间。
- Owner/Editor 才能对失败演练执行一次“仅重试失败专家”。
- 匿名公共 A2MCP 失败后必须重新提交完整 SOP，不能读取部分结果。

## 安全提示

不要在 SOP 正文、分享链接、X 帖子或截图中放入 API Key、密码、Session Secret 或真实客户数据。生产服务使用 HTTPS、RBAC、限流、CSP 和安全错误响应。
